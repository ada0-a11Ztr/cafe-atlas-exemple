# Café Atlas, site d'exemple

Site d'exemple (café fictif à Agadir) : trois langues (français, arabe, anglais), WhatsApp, horaires, carte, galerie et réservation.

Les noms, adresses, numéros, horaires et prix sont inventés. Les photos viennent de Wikimedia Commons (licences libres, auteurs sur `credits.html`).

Ouvrir `index.html` dans un navigateur suffit, aucune installation.
